Jelly is a client for Jellyfin, the free and open-source media server that people run on their own computer or NAS. The app contains no content of its own; it plays the user's own library from the user's own server. This is the Mac version of the app that is already on the App Store for Apple TV, iPhone and iPad (same bundle ID, universal purchase).

HOW TO REVIEW (public demo server of the Jellyfin project, public-domain and Creative Commons films only)
1. Launch Jelly. In the field "Server Address", enter: demo.jellyfin.org/stable and click "Connect".
2. Choose the profile "demo", leave the password empty and click "Sign In".
3. Browse the library with the sidebar and play e.g. "Caminandes: Llama Drama". Move the pointer over the video for the controls; the options button opens subtitles, audio, quality and info. The Playback menu has keyboard shortcuts (Space, arrow keys).

SUBSCRIPTION (Guideline 3.1.2)
- The app is free to download and unlocked by the auto-renewable subscription "Jelly Annual" (1 year, 9.99 EUR) with a 2-week free trial as introductory offer. The same subscription unlocks Jelly on Apple TV, iPhone and iPad (universal purchase).
- The offer appears once after signing in and whenever playback is started without an active subscription. It states the price per year, the trial, automatic renewal and how to cancel, and links to the Terms of Use (Apple's standard EULA) and the Privacy Policy.
- Settings (in the sidebar) > Annual Subscription shows the status and offers subscribing, "Restore Purchases" and managing the subscription. Browsing the library works without a subscription.

NOTES
- App Sandbox with network access only: connections to the user's Jellyfin and Jellyseerr servers, and a local loopback server inside the app through which the player engine reads the stream. No file access outside the app's container; downloads are stored there.
- Local network access is used only to discover Jellyfin servers in the user's home network (TCP 8096) and to reach the server directly at home.
- App Transport Security exception: home media servers are usually reached via plain HTTP on the local network (e.g. http://192.168.1.10:8096) or user-chosen host names, so per-domain exceptions are not possible.
- Watch together: SharePlay (Group Activities) starts playback for everyone in a FaceTime call. SyncPlay (Settings > Extras) is the Jellyfin server's own watch-together feature.
- Kids profile (Settings > Kids Profile): limits the library to an age rating taken from the server and protects Settings, profile switching and Discover with a PIN stored in the keychain.
- The "Discover" tab is optional. It connects to the user's own Jellyseerr server, a companion request manager for Jellyfin; without one it only explains how to connect it. The demo server has no Jellyseerr.
- No data is collected; there is no analytics, advertising or tracking.
- The interface follows the device language: English, German, French, Spanish, Italian, Dutch, Portuguese (Brazil), Danish, Swedish and Polish.
