Jelly is a client for Jellyfin, the free and open-source media server that people run on their own computer or NAS. The app contains no content of its own; it plays the user's own library from the user's own server.

HOW TO REVIEW (public demo server of the Jellyfin project, public-domain and Creative Commons films only)
1. Launch Jelly. If no server is found automatically, choose "Enter Address".
2. Enter: demo.jellyfin.org/stable
3. Select the profile "demo", leave the password empty and choose "Sign In".
4. Browse the library and play e.g. "Caminandes: Llama Drama". Swipe down during playback for subtitles, audio and info.

SUBSCRIPTION (Guideline 3.1.2)
- The app is free to download and unlocked by the auto-renewable subscription "Jelly Annual" (1 year, 9.99 EUR) with a 2-week free trial as introductory offer. The same subscription unlocks Jelly on iPhone, iPad and Mac (universal purchase).
- The offer appears once after signing in and whenever playback is started without an active subscription. It states the price per year, the trial, automatic renewal, how to cancel, and links to the terms of use (Apple's standard EULA) and the privacy policy (shown as address and QR code, the privacy policy also as text, since tvOS has no browser).
- Settings > Annual Subscription shows the status and offers subscribing and "Restore Purchases". Browsing the library works without a subscription.

NOTES
- Local network access is used only to discover Jellyfin servers in the user's home network (UDP 7359 and TCP 8096).
- App Transport Security exception: home media servers are usually reached via plain HTTP on the local network (e.g. http://192.168.1.10:8096) or user-chosen host names, so per-domain exceptions are not possible.
- The "Discover" tab is optional. It connects to the user's own Jellyseerr server, a companion request manager for Jellyfin; without one it only explains how to connect it. The demo server has no Jellyseerr.
- No data is collected; there is no analytics, advertising or tracking.
- The interface follows the device language: English, German, French, Spanish, Italian, Dutch, Portuguese (Brazil), Danish, Swedish and Polish.


NEW IN 2.0
- Sign in with iPhone: the Quick Connect screen shows a QR code that Jelly on the iPhone opens to confirm the code. It needs a Jellyfin server with Quick Connect enabled; password sign-in works as before.
- Watch together: SharePlay (Group Activities) starts playback for everyone in a FaceTime call. SyncPlay (Settings > Extras) is the Jellyfin server's own watch-together feature.
- Kids profile (Settings > Kids Profile): limits the library to an age rating taken from the server and protects Settings, profile switching and Discover with a PIN stored in the keychain.
- HomeKit (optional, off by default; Settings > Extras > Home Cinema Scenes): the viewer can choose one of their own HomeKit scenes to run when playback starts and another when it pauses or ends, e.g. to dim the lights. Jelly only reads the list of scenes and runs the chosen ones; nothing leaves the device.
- Apple TV users: Jelly runs as the current Apple TV user (com.apple.developer.user-management: runs-as-current-user), so each person has their own settings and active profile.
- Theme music (optional, off by default) plays a series' theme song from the user's server on its detail page.
